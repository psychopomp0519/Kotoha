# Kotoha — 言の葉

일본 판타지 방치형 RPG. 갈대의 땅 아시하라에서 길드 마스터로서 모험가를 모집하고 원정을 떠나보세요.

## 기술 스택

- Vite 6 + React 19 + TypeScript (strict)
- Zustand (상태 관리)
- IndexedDB (세이브)
- seedrandom (결정론적 RNG)
- Vitest (테스트)

## 실행

```bash
npm install
npm run dev
```

## 테스트

```bash
npm test
```

## 빌드

```bash
npm run build
```
