## 오프라인 진행

### 오프라인에서 계속되는 것

| 시스템 | 오프라인 진행 | 효율 |
|--------|--------------|------|
| 원정 | 파견된 원정 계속 진행 (안전 루트) | 회당 100%, 시간당 60~70% |
| 시설 생산 | 자원/아이템 자동 생산 | 100% |
| 도장 훈련 | 배치된 모험가 경험치 축적 | 100% |
| 자원 채취 | 정화된 지역에서 자원 자동 유입 | 100% |
| 이벤트 | 발생하지 않음 (능동 전용) | 0% |
| 모집소 갱신 | 타이머에 따라 갱신 | 100% |

### 오프라인 축적 상한

- **기본 상한**: 24시간 — **1일 1회 접속으로 손실 제로**
- **숙소 업그레이드**: +4시간/레벨 (최대 36시간)
- **환생 보너스**: +4시간/환생 횟수 (최대 +12시간)
- **최대 상한**: 48시간 (2일 미접속도 24시간분 보장)
- 24시간 이내 복귀 시 **어떤 불이익도 없음** — 이것이 설계 대원칙
- 상한 초과분만 소실, 이마저도 48시간 확장으로 여유 있음

### 시설 오프라인 생산

```
오프라인 시설 생산량 = 시설 Lv × 기본 생산율 × 경과 틱 × 효율

효율:
  제작 대기열: 대기열에 있는 아이템만 제작 (빈 대기열 = 생산 중단)
  자원 생산 (정원 등): 밭 슬롯 × 작물별 수확 사이클
  훈련 (도장): 배치된 모험가 수 × 경험치율

상한: 각 시설의 저장 공간에 따라 (창고 레벨 기반)
  예: 약제실 Lv 5 → 물약 최대 20개 보관, 초과분 소멸
```

### 원정 자동 반복

오프라인 중에도 원정은 자동 반복된다:

- 원정 완료 → 같은 목적지·같은 파티로 즉시 재파견
- 소모품 소진 시 소모품 없이 계속 (기본 상태)
- 모험가 HP 30% 미만 시 자동 귀환 → 회복 후 재파견
- 보스(깊이 5)는 자동 반복 제외
- 부재 중 보고서에서 "×N회 완료"로 표시

---

### 오프라인 계산 방식

```
복귀 시:
1. 경과 시간 계산 (최대 = 축적 상한)
2. 경과 틱 수 = 경과 초
3. 원정: 조우 시퀀스를 고속 시뮬레이션 (전투는 결과만 계산)
4. 시설: 생산량 × 경과 틱 (상한 적용)
5. 훈련: 경험치 × 경과 틱
6. 결과를 "부재 중 보고서"로 표시
```

### 능동 vs 방치

> **방치 = 안전한 성장. 회당 보상 동일, 안전 루트로 자연스럽게 느린 진행.**
> **능동 = 효율 + 발견 + 도전. 최적 루트, 보스, 이벤트는 능동에서만.**

| 요소 | 방치 | 능동 |
|------|------|------|
| 회당 경험치/금화/드롭 | 100% | 100% (동일) |
| 시간당 총수입 | 60~70% (안전 루트) | 100% (최적 루트) |
| 시설 생산 | 100% | 100% (동일) |
| 요괴 도감 축적 | 미축적 | **관찰 시 축적 → 영구 데미지 보너스** |
| 보스 도전 | **불가** | **능동에서만 가능** |
| 이벤트 | 기본 선택 자동 | 직접 선택 + 숨겨진 선택지 |
| 숨겨진 발견 | 기본 확률 | +30% |

방치로 성장, 능동으로 도전. 보스는 능동 전용 — 이것이 열어야 하는 이유.

## 환생 시스템 (윤회전생 / 輪廻転生)

### 개요

환생은 코토하의 **메타 진행 시스템**이다. 현재 진행을 리셋하는 대신 영구적 강화를 얻는다.
세계관적으로는 "카미의 축복으로 시간을 되돌린다"로 설명된다.

### 환생 조건

| 환생 횟수 | 최소 조건 | 해금되는 이면 |
|-----------|----------|--------------|
| 1회차 | 제5국 클리어 + Lv 60+ 모험가 2명 | 제1~2국 이면 |
| 2회차 | 제7국 클리어 + Lv 75+ 모험가 3명 | 제3~4국 이면 |
| 3회차 | 제10국 클리어 + Lv 90+ 모험가 4명 | 제5~6국 이면 + 삼종신기 퀘스트 |
| 4회차 | 이면 지역 3개 클리어 | 제7~8국 이면 |
| 5회차+ | 이면 지역 추가 클리어 | 나머지 이면 + 최종 콘텐츠 |

### 환생 = 부분 리셋 + 폭발적 성장감

> **핵심: 모험가 레벨만 리셋. 나머지는 전부 유지. 그리고 더 강해진다.**
> 환생의 쾌감은 "어제 3주 걸렸던 보스를 오늘 3일 만에 쓰러뜨리는" 가속감에 있다.

### 환생 시 리셋되는 것

- **모험가 레벨** → Lv 1로 (클래스 Tier 0로 복귀)
- **지역 진행** → 제1국부터 다시 (보스 재도전 필요)

### 환생 시 유지되는 것

- **시설**: 레벨 전부 유지 — 처음부터 풀 시설로 시작
- **금화 & 아이템**: 전부 유지 — 최고급 장비로 Lv 1부터 무쌍
  - **환생자 특권**: 장비의 착용 최소 레벨 제한 무시 (카미의 축복으로 모든 장비 착용 가능)
  - 이것이 환생의 핵심 쾌감: Lv 1 모험가가 전설 장비를 들고 제1국을 무쌍
- **도감**: 요괴/아이템/클래스 기록 유지 — 보스 약점 정보 그대로
- **이벤트 기록 & 칭호**: 유지
- **유대 기억**: 이전 환생의 유대 관계는 "기억"으로 남아, 같은 모험가 조합 시 유대 축적 ×2
- **클래스 경험**: 이전에 달성한 클래스는 도감에 기록 → 전직 조건 중 레벨 요구만 적용 (스탯/아이템 조건 면제)

### 환생으로 얻는 것

- **곡옥(勾玉)** 획득 (기존 공식 동일)
- **깨달음(悟り) 보너스**:
  - 전 모험가 스탯 +5%/환생 (영구 누적) — Lv 1이어도 이전보다 강하다
  - 경험치 획득 +15%/환생 (영구 누적) — 레벨업이 눈에 띄게 빨라진다
- **이면(裏面) 콘텐츠 해금**:
  - 클리어했던 지역의 "이면 버전" 해금 — 강화된 적, 새 보스, 새 전리품
  - 이면은 환생 후 해당 지역 재클리어 시 자동 해금
- **새 이벤트 시드** → 이전 환생에서 못 본 이벤트 우선
- **Tier 5~6 전직 조건** 충족 (환생 횟수)
- **삼종신기 퀘스트** 해금 (환생 3회+)

### 환생의 쾌감 사이클

```
1회차: 제1국 보스에 2주 걸림
         ↓ 환생 (깨달음 +5%, 경험치 +15%, 풀 시설, 최고급 장비)
2회차: 제1국 보스를 3일 만에 돌파! → 이전에 못 갔던 깊이까지
         ↓ 환생
3회차: 제1국~3국을 1주일에 돌파! → 이면 콘텐츠 도전
```

> 환생할수록 **같은 콘텐츠가 다르게 느껴진다.**
> 처음엔 고전했던 보스를 한 방에 쓰러뜨리는 쾌감.
> 그리고 이면에서 만나는 더 강한 버전에서 다시 고전하는 긴장감.

### 곡옥 (勾玉 / Magatama)

환생 시 획득하는 영구 화폐.

#### 곡옥 획득량

```
기본 곡옥 = 클리어 지역 수 × 10
보너스 곡옥 = 최고 레벨 모험가 Lv ÷ 10 (내림)
           + 처치 보스 수 × 5
           + 전설 아이템 보유 수 × 3
           + 도감 완성률 × 50
```

도감 완성률 = (발견 요괴 + 획득 아이템 + 경험 클래스) ÷ (전체 요괴 + 전체 아이템 + 전체 클래스)
※ 분모는 현재 구현된 콘텐츠 총량 기준 (Phase별 자동 조정)

예시: 3지역 클리어, Lv 52 최고, 보스 3체, 전설 2개, 도감 15%
= 30 + 5 + 15 + 6 + 7 = **63 곡옥**

#### 곡옥 상점 (영구 강화)

| 강화 | 비용 | 효과 | 최대 |
|------|------|------|------|
| 초기 금화 증가 | 5 | 시작 금화 +500 | 20회 |
| 경험치 배율 증가 | 10 | 경험치 +10% | 20회 |
| 모집 품질 향상 | 15 | 모집 모험가 초기 스탯 +2 | 10회 |
| 시설 건설 속도 | 8 | 건설 시간 -5% | 10회 |
| 오프라인 상한 증가 | 12 | +2시간 | 6회 |
| 원정 슬롯 확장 | 30 | +1 슬롯 (3번째, 4번째) | 2회 |
| 모험가 보유 확장 | 20 | +2명 | 5회 |
| 전직 레벨 감소 | 25 | 전직 필요 레벨 -1 | 10회 |
| 드롭률 증가 | 15 | 전리품 드롭률 +5% | 10회 |
| 스탯 성장률 증가 | 20 | 레벨업 스탯 +5% | 10회 |
| 초기 시설 레벨 | 15 | 시작 시 시설 Lv2 | 5회 |
| 환생 금고 확장 | 25 | 보관 슬롯 +1 | 5회 |
| 펫 슬롯 확장 | 30 | 펫 +1 (길드) | 3회 |
| 히든 클래스 단서 | 50 | 히든 클래스 조건 힌트 해금 | 5회 |
| 신화 클래스 해금 | 100 | Tier 6 전직 가능 | 1회 (환생 3+ 필요) |

#### 곡옥 총 소비량 추정

모든 강화 최대: ~2,500 곡옥
→ 완전 강화까지 약 15~20회 환생 필요 (장기 목표)

## 삼종신기 퀘스트 (三種神器)

환생 3회 이상에서 해금되는 특수 퀘스트 체인. 각 신기를 입수하면 Tier 6 전직 조건의 일부가 충족된다.

### 아마노무라쿠모(天叢雲剣) — 검

- **해금 조건**: 환생 3회+, 제5국(유키시로) 클리어
- **퀘스트**: "폭풍의 검" 연쇄 이벤트 (3단계)
  1. 쿠라야미다니 최심부에서 "검의 제단" 발견
  2. 풍뢰 원소 보스 "야마타노오로치의 잔영" 격파
  3. 제단에 풍뢰 소재 5종 봉납
- **효과**: 전 원소 내성 +30%, 검사 T6 전직 해금

### 야타노카가미(八咫鏡) — 거울

- **해금 조건**: 환생 3회+, 전 지역 신사 방문
- **퀘스트**: "빛의 거울" 연쇄 이벤트 (3단계)
  1. 하나카게 숨겨진 신사에서 "거울의 파편" 발견
  2. 전 지역 보스를 한 환생 내에 재격파
  3. 요미지 입구에서 "이자나기의 시련" 클리어
- **효과**: 술법 반사 30%, 무녀 T6 전직 해금

### 야사카노마가타마(八尺瓊勾玉) — 곡옥

- **해금 조건**: 환생 3회+, 곡옥 총 획득 300+
- **퀘스트**: "생명의 곡옥" 연쇄 이벤트 (3단계)
  1. 환생 시 특수 선택지 "카미의 음성" 출현
  2. 새 회차에서 제1~3국을 7일 이내 클리어
  3. 요미지에서 "이자나미의 시련" 클리어
- **효과**: 전투 중 자동 부활 1회, 야마부시 T6 전직 해금

### 삼종신기 동시 보유

- 3개 모두 보유 시 히든 클래스 "삼종신기 소유자" 해금
- 환생해도 삼종신기는 환생 금고에 자동 보관 (슬롯 소비 없음)

## 환생 회차별 변화

| 회차 | 새로 해금되는 것 |
|------|-----------------|
| 1 | 환생 시스템 자체, 곡옥 상점, 새 시드로 이벤트 변화 |
| 2 | Tier 5(전설) 전직 가능, 일부 히든 이벤트 |

| 7 | 전 지역 "이면(裏面)" 해금 — 강화된 적 + 새 전리품 |
| 10 | 최종 히든 클래스 "카미(神)" 조건 해금 |

```
     ^
     │                                    ★ 환생 10회
     │                              ★
     │                        ★
     │                  ★
     │            ★
     │      ★          ← 각 환생마다 더 높은 천장
     │  ★     리셋
     │★   ↗ /
     │  ↗ /
     │↗ /
     ├──/──────────────────────→ 시간
     환생1  환생2  환생3  ...
```

### 환생 가속

- 1회차: 제3국까지 ~3주
- 2회차: 같은 지점까지 ~2주 (곡옥 강화 덕분)
- 3회차: ~10일
- 5회차+: ~1주
- 10회차+: ~3~4일 (콘텐츠 소비보다 최적화 중심)

## 칭호 시스템

칭호는 환생해도 유지되며, 장식적 효과 + 소량의 실질 보너스를 준다.

### 칭호 예시

| 칭호 | 조건 | 보너스 |
|------|------|--------|
| 초심자(初心者) | 첫 원정 완료 | 없음 |
| 요괴 사냥꾼(妖怪狩り) | 요괴 100체 처치 | 요괴 경험치 +2% |
| 천리안(千里眼) | 숨겨진 장소 50개 발견 | 발견 확률 +3% |
| 명 길드 마스터(名ギルド長) | 모험가 20명 동시 보유 | 모집 비용 -5% |
| 윤회의 자(輪廻の者) | 환생 5회 | 환생 곡옥 +10% |
| 전설의 장인(伝説の匠) | 전설 장비 10개 제작 | 제작 품질 +5% |
| 요괴의 벗(妖怪の友) | 요괴 유대 이벤트 20회 | 케모노 계통 스탯 +3% |
| 천하무쌍(天下無双) | 보스 전멸 없이 격파 30회 | 전투 공격력 +3% |
| 불사(不死) | 환생 10회 달성 | 전 스탯 +5% |
