# 01 — Core Loop (핵심 루프)

> 모집 → 편성 → 파견 → 전투 → 보상 → 강화 → 반복

---

## 루프 계층 구조

코토하의 게임플레이는 세 겹의 중첩된 루프로 구성된다.

```
┌─────────────────────────────────────────────┐
│  메타 루프 (수 일~수 주)                       │
│  새 지역 해금 → 스토리 진행 → 환생            │
│                                               │
│  ┌─────────────────────────────────────────┐ │
│  │  세션 루프 (5~15분)                       │ │
│  │  결과 확인 → 관리 → 이벤트 → 파견         │ │
│  │                                           │ │
│  │  ┌─────────────────────────────────────┐ │ │
│  │  │  이너 루프 (자동, 수 초~수 분)        │ │ │
│  │  │  조우 → 전투 → 전리품 → 다음 조우     │ │ │
│  │  └─────────────────────────────────────┘ │ │
│  └─────────────────────────────────────────┘ │
└─────────────────────────────────────────────┘
```

---

## 이너 루프 (자동 — 방치 중에도 진행)

플레이어 개입 없이 자동으로 반복되는 가장 작은 단위의 루프.

### 흐름

```
원정 시작
  └→ 조우 발생 (전투 / 함정 / 발견 / 이벤트)
       └→ [전투일 경우] 자동 전투 해결
            └→ 승리: 전리품 획득 + 경험치
            └→ 패배: 기 소진, 캠프에서 회복 or 귀환
       └→ [발견일 경우] 자원/아이템 자동 획득
       └→ [이벤트일 경우] 사전 설정 or 기본 선택으로 자동 처리
  └→ 다음 조우로 이동
  └→ 원정 완료 or 전멸 시 길드로 귀환
```

### 특성

- **완전 자동**: 플레이어가 보지 않아도 진행
- **틱 기반**: 1틱 = 1초. 오프라인 시 경과 틱만큼 고속 시뮬레이션
- **전투 로그**: 전투 결과는 텍스트 로그로 기록, 복귀 시 열람 가능
- **원정 시간**: 지역 난이도 × 깊이에 따라 수 분(쉬움)~수 시간(깊은 탐험)

## 세션 루프 (능동 — 5~15분 체크인)

플레이어가 게임에 돌아와서 수행하는 의사결정 사이클.

### 흐름

```
게임 복귀
  └→ 1. 부재 중 보고서 확인
       - 완료된 원정 결과 (전투 로그, 획득 아이템, 경험치)
       - 시설 생산 결과 (축적된 자원)
       - 훈련 결과 (레벨업, 스킬 습득)
       - 발생한 이벤트 요약
  └→ 2. 전리품 정리
       - 아이템 정리, 장비 비교/교체
       - 자원을 시설에 투입 (제작 시작)
  └→ 3. 모험가 관리
       - 새 모험가 모집 (모집소에 후보 목록)
       - 레벨업한 모험가 전직 결정
       - 부상/요기 침식 모험가 치료
       - 장비 변경, 스킬 배치
  └→ 4. 시설 관리
       - 업그레이드 가능한 시설 확인
       - 제작 대기열 설정
       - 새 시설 건설 (해금 조건 충족 시)
  └→ 5. 이벤트 처리
       - 시드 기반 이벤트 발생 시 선택지 결정
       - 이벤트 결과 확인 (이전 선택의 후속)
  └→ 6. 다음 원정 편성 & 파견
       - 파티 구성 (모험가 4명 + 펫 1마리)
         ※ 펫: 펫 소굴(獣舎)에서 관리, 파티에 동행하여 패시브 효과/보조 행동
         → 상세: `08-equipment-system.md` Part B
       - 목적지 선택 (지역 & 깊이)
       - 소모품 장착 (음식, 물약, 부적)
       - 파견! (자동 반복 설정 가능)
  └→ 게임 닫기 or 계속 관찰 — 원정은 자동 반복되므로 안심하고 떠날 수 있다
```

### 핵심 의사결정 포인트

| 시점 | 결정 | 영향 |
|------|------|------|
| 모집 | 어떤 계통의 모험가를 뽑을 것인가 | 장기적 길드 구성 |
| 전직 | 어떤 상위 클래스로 전직시킬 것인가 | 모험가의 역할 특화 |
| 편성 | 누구를 어떤 조합으로 보낼 것인가 | 원정 성공률, 효율 |
| 목적지 | 어디를, 얼마나 깊이 탐험할 것인가 | 리스크 vs 보상 |
| 제작 | 무엇을 만들고, 누구에게 줄 것인가 | 전력 배분 |
| 이벤트 | 어떤 선택지를 고를 것인가 | 후속 이벤트, 보상/페널티 |

### 원정 자동 반복 (自動再派遣)

원정 완료 시 같은 목적지·같은 파티로 **자동 재파견**된다.

- 방치의 핵심 루프: 파견 → 완료 → 자동 재파견 → 반복
- 자동 반복 중에도 소모품(음식, 물약, 부적)은 매 원정마다 소비
- 소모품 소진 시 소모품 없이 계속 출발 (기본 상태로 원정)
- 보스(깊이 5)는 자동 반복 대상에서 **제외** (능동 전용)
- 모험가 HP가 30% 미만이면 자동 귀환 후 회복 대기 → 회복 후 재파견
- 원정 슬롯 화면에서 자동 반복 ON/OFF 토글 가능

### 능동 플레이 보너스

**방치가 기본이다. 능동은 "발견"이다.**

**회당 보상(경험치, 금화, 드롭률)은 방치와 능동이 완전히 동일하다.** 전투 1회의 보상에 차이 없음.
단, 방치 원정은 **안전 루트(安全路)**로 자동 진행하여 조우 수가 줄어든다:
- 방치 시: 기본 조우 수의 60~70% (안전한 길을 택하므로)
- 능동 관찰 시: 지름길, 밀집 구역 발견 → 조우 수 100%
- **결과적으로 시간당 수입은 방치 시 자연스럽게 낮아지되, "회당 보상률"은 완전 동일**
- 방치는 "패널티"가 아니라 "신중한 탐험"이다

능동 플레이에는 추가로 **방치로는 얻을 수 없는 고유 콘텐츠**가 있다:

### 능동 전용: 관찰 시스템 (観察)

전투 로그를 실시간으로 관찰하면 **도감 정보**가 축적된다:

- **요괴 관찰**: 전투를 지켜보면 해당 요괴의 약점/패턴이 도감에 기록됨
  - 도감 완성 시: 해당 요괴에 영구 +5% 데미지 (최대 +15%)
  - 방치 원정에서는 "전투 결과"만 기록, 도감 정보는 미축적
- **지형 관찰**: 원정을 관찰하면 숨겨진 루트/비밀 발견 확률 상승
  - 관찰 시 발견 확률 +30% (방치 시 기본 확률)
- **모험가 관찰**: 전투 관찰 중 모험가의 유대 이벤트가 발생할 수 있음
  - 관찰 중에만: "야요이가 카에데를 감싸 안았다" 같은 유대 연출 확인

### 능동 전용: 이벤트 선택

- 능동 시 이벤트 선택지를 **직접 결정**
- 방치 시 기본 선택 자동 (나쁜 선택은 아님, 다른 선택일 뿐)
- 단, 일부 연쇄 이벤트의 **숨겨진 선택지**는 관련 도감 정보가 있을 때만 등장
  - 예: 요괴 도감에서 여우 정보를 읽었으면 → "여우의 언어로 말을 건다" 선택지 추가

### 능동 전용: 보스 도전 모드

- 보스전은 **반드시 능동 상태에서만 도전** 가능 (방치 중 보스 자동 도전 불가)
- 보스전 관찰 시: 보스의 페이즈 패턴이 도감에 기록 → 다음 도전 시 유리
- 보스는 방치로 이길 수 없는 유일한 콘텐츠 — **능동의 존재 이유**

### 정리: 방치 vs 능동

> **방치 = 성장과 자원 축적. 손해 없음.**
> **능동 = 발견과 도전. 능동해야만 열리는 콘텐츠가 있음.**
> **보스는 능동 전용. 이것이 게임을 여는 이유.**

### 일일/주간 퀘스트 (의뢰 게시판)

주점(酒場)의 의뢰 게시판에서 매일/매주 갱신되는 퀘스트를 수령한다.

**일일 퀘스트** (매일 3개 자동 생성):
- 전투형: "X 요괴 N마리 처치" → 경험치 + 금화
- 수집형: "소재 X를 N개 획득" → 금화 + 희귀 소재
- 탐험형: "Y 지역 깊이 Z 클리어" → 경험치 + 장비 소재

**주간 퀘스트** (매주 2개):
- "보스 재도전" → 주간 전용 소재 + 대량 경험치
- "길드 목표 달성" (시설/유대/도감 등) → 특수 보상

퀘스트 진행은 방치/능동 모두 가능. 미완료 시 소멸하되 다음날 유사 퀘스트 재등장.
연속 완료 보너스: 7일 연속 일퀘 완료 → 주간 보너스 소재.

## 메타 루프 (장기 — 수 일~수 주)

게임의 큰 흐름을 만드는 최상위 루프.

### 흐름

```
게임 시작 (제1국: 아사기리)
  └→ 현재 지역 탐험 반복
       - 세션 루프 반복
       - 점진적으로 더 깊은 곳 진입
  └→ 지역 보스 공략
       - 보스 공략 조건 충족 (레벨, 장비, 특정 아이템)
       - 보스 전투 (특수 규칙 적용)
       - 승리 시 지역 정화 + 다음 지역 해금
  └→ 새 지역 진입
       - 새로운 요괴, 자원, 클래스 분기 해금
       - 스토리 챕터 진행
  └→ [선택] 환생 (윤회전생)
       - 일정 조건 충족 시 환생 가능
       - 모든 진행 리셋 → 곡옥(마가타마) 획득
       - 곡옥으로 영구 강화 구매
       - 다음 회차에서 더 빠르게 진행 + 더 깊은 콘텐츠 해금
  └→ 반복 (매 회차마다 새로운 이벤트 시퀀스)
```

### 진행 감각

| 시점 | 플레이어 감각 |
|------|---------------|
| 1일차 | "오, 이 모험가 괜찮은데?" — 모집과 첫 원정의 신선함 |
| 3일차 | "이 조합이면 더 깊이 갈 수 있겠다" — 편성 전략 형성 |
| 1주차 | "드디어 보스를 잡았다!" — 첫 지역 클리어의 성취감 |
| 2주차 | "이 클래스 트리 끝까지 가봐야지" — 빌드 목표 형성 |
| 3~4주차 | "환생하면 이번엔 시노비 중심으로..." — 환생 동기 |
| 2회차 | "이 이벤트는 전에 못 본 건데?" — 시드 기반 변화 체감 |

## 자원 흐름도

```
원정 (전리품)
  ├→ 소재 → 카지바(제작) → 장비 → 모험가 장착
  ├→ 약초 → 야쿠자이시츠(조제) → 물약 → 원정 소모품
  ├→ 식재료 → 츄보(요리) → 음식 → 원정 버프
  ├→ 영물 → 후다바(부적) → 오후다 → 원정 보호
  └→ 금화 → 시설 업그레이드 / 모험가 모집 / 장비 강화

모험가 (성장)
  ├→ 경험치 → 레벨업 → 스탯 증가
  ├→ 도장 훈련 → 스킬 습득 / 전직 조건 충족
  └→ 유대 → 파티 시너지 보너스

환생
  └→ 곡옥 → 영구 강화 (시작 자원↑, 경험치 배율↑, 새 콘텐츠 해금)
```

## 방치 vs 능동 비교

| 요소 | 방치 시 | 능동 시 |
|------|---------|---------|
| 회당 경험치/금화/드롭 | **100%** | **100% (동일)** |
| 시간당 총수입 | **60~70%** (안전 루트) | **100%** (최적 루트) |
| 시설 제작 | **100%** | **100% (동일)** |
| 요괴 도감 축적 | 미축적 | **관찰 시 축적 → 영구 보너스** |
| 숨겨진 발견 | 기본 확률 | **+30%** |
| 이벤트 | 기본 선택 자동 | **직접 선택 + 숨겨진 선택지** |
| 보스 도전 | **불가** | **능동에서만 가능** |
| 유대 연출 | 수치만 축적 | **스토리 이벤트 확인** |
| 일일 퀘스트 | 자동 진행 | 수령 + 갱신 |

> **방치 = 안전한 성장.** 잠자는 동안에도 길드는 강해진다. 회당 보상은 동일하되, 안전 루트로 느리게.
> **능동 = 효율 + 발견 + 도전.** 최적 루트 탐색, 도감 채우기, 보스 도전, 이야기 선택.
> **보스는 능동 전용** — 이것이 게임을 열어야 하는 이유.

## 신규 플레이어 첫 10분 — "훅"

> 첫 10분에서 플레이어를 잃으면 끝이다. 이 구간은 게임에서 가장 중요하다.

**0분: 즉시 시작**
- 길드 이름만 입력 (기본: コトハ屋). 긴 설명 없음.
- **모험가 3명이 이미 있다** — 검사, 무녀, 시노비가 길드 창립 멤버로 대기 중.
- "이 세 명이 당신을 기다리고 있었습니다." 한 줄이면 충분.

**1분: 첫 원정 — 1분짜리 "시범 원정"**
- 튜토리얼 전용 **초단거리 원정** (60틱 = 1분). 전투 1회 + 보물 1개.
- 원정 진행이 실시간 텍스트로 흘러간다:
  ```
  야요이(剣士)가 숲에 들어섰다...
  타누키 한 마리가 뛰어나왔다!
  야요이가 베기를 날렸다 — 28 피해. 타누키 쓰러짐!
  → 오니의 뿔 ×1, 금화 15 획득.
  카에데(巫女)가 약초를 발견했다.
  ```
- **기다리는 게 아니라 읽는 것.** 텍스트가 실시간으로 흘러가며 세계를 보여준다.

**3분: 첫 보상 + 즉시 두 번째 파견**
- 전리품 확인. 첫 장비(낡은 카타나) 즉시 장착 가능.
- "더 깊은 곳에 가볼까요?" → 3분짜리 원정 파견.

**5분: 첫 이벤트**
- 두 번째 원정 대기 중 **강제 이벤트 발생** (튜토리얼 전용):
  ```
  비가 그친 뒤, 길드 문 앞에 하얀 여우 한 마리가 앉아 있었다.
  꼬리가 셋이었다.

  · 다가간다
  · 음식을 건넨다
  ```
- 이 이벤트가 게임의 정체성을 보여준다: **텍스트가 이 게임의 그래픽이다.**

**8분: 네 번째 모험가 모집 + 파티 편성**
- 두 번째 원정 귀환. 전리품 + 경험치.
- 모집소에서 4번째 모험가 영입 → **첫 4인 파티 편성.**
- "전위/후위를 배치하세요" → 첫 전략적 선택.

**10분: 게임을 닫을 때**
- 4인 파티가 5분 원정에 출발한 상태.
- 화면에 표시: "원정 진행 중... 결과는 돌아오면 확인하세요."
- **"내일 아침 뭐가 쌓여있을까?"** — 이 기대감이 첫 리텐션.

### 핵심: 첫 10분의 규칙

1. **기다리게 하지 않는다** — 첫 원정은 1분. 읽을 것이 항상 있다.
2. **선택할 것을 준다** — 이벤트 선택, 장비 장착, 파티 편성.
3. **세계를 보여준다** — 시스템 설명이 아닌 이야기로.
4. **닫을 때 미련을 남긴다** — 진행 중인 원정이 있는 상태로.
