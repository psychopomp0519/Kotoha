## 강화 시스템

### 기본 강화

- 대장간에서 **강화석 + 금화** 사용
- 강화 단계: +1 ~ +10
- 단계당 기본 스탯 +5%
- 강화 실패 확률: +1~5 (0%), +6~7 (20%), +8~9 (35%), +10 (50%)
- 실패 시: 강화 단계 유지 (하락 없음), 소재만 소실

### 원소 부여

- 부적방의 오후다를 사용하여 무기에 원소 속성 부여
- 부여 가능 원소: 오행(목/화/토/금/수)
- 이미 원소가 있는 무기에 중복 부여 → 원소 변경
- 고급 오후다로 원소 데미지 +10~20% 추가

# Part B: 펫 시스템

> 요괴의 세계에서, 때로는 요괴 자신이 최고의 동반자가 된다.

## 펫 개요

- 펫은 원정에 파티와 함께 동행하는 **동반자**
- 전투에 직접 참여하지 않지만, **패시브 효과와 탐험 보너스** 제공
- 일부 고급 펫은 전투 중 **보조 행동** 수행
- 펫도 성장하며, 모험가와 유대를 맺는다

## 펫 입수

| 방법 | 설명 |
|------|------|
| 원정 포획 | 특정 조우에서 요괴를 포획 (포획 아이템 필요) |
| 이벤트 | 시드 기반 이벤트 보상으로 펫 획득 |
| 부화 | 원정에서 얻은 알을 시간 경과 후 부화 |
| 교환 | 교역소에서 희귀 소재로 교환 |
| 선물 | NPC 요괴와의 유대 이벤트로 동행 결정 |

### 포획 시스템

- **포획 부적(捕獲札)**: 부적방에서 제작
- 포획 확률: 기본 10% + (요괴 HP 비율 낮을수록↑) + 부적 등급 보너스
- 보스 요괴는 포획 불가 (단, 이벤트로 미니 버전 획득 가능)

## 펫 성장

### 레벨

- 펫도 원정에서 경험치 획득 (파티 경험치의 30%)
- 최대 레벨: 50
- 레벨업 시 패시브 효과 수치 증가

### 유대 (펫-모험가)

- 특정 모험가와 자주 동행하면 펫 유대 형성
- 유대 단계: 낯섦(0) → 친숙(1) → 파트너(2) → 영혼의 벗(3)
- 유대 효과: 보조 행동 빈도 증가, 전용 합동 스킬 해금

### 진화

일부 펫은 조건 충족 시 상위 종으로 진화한다.

| 진화 경로 | 조건 |
|-----------|------|
| 코타누키(★) → 타누키(★★) | 펫 Lv 15 + 타누키 먹이(주방 제작) ×5 |
| 타누키(★★) → 봉래타누키(★★★) | 펫 Lv 30 + 봉래의 잎(제3국 드롭) ×3 + 이벤트 "타누키의 소원" |
| 아기여우(★) → 이나리 여우(★★★) | 펫 Lv 25 + 여우 구슬(이벤트 보상) + 신사 3곳 방문 |
| 이나리 여우(★★★) → 구미호 새끼(★★★★) | 펫 Lv 40 + 구미호 소재(제4국 보스) + 환생 1회+ |
| 코카파(★) → 카파(★★) | 펫 Lv 15 + 오이(정원 재배) ×10 |
| 까마귀(★) → 야타가라스(★★★★) | 펫 Lv 35 + 태양석(제5국 드롭) + 이벤트 "삼족오의 시련" + 환생 2+ |
| 들토끼(★) → 유키우사기(★★★) | 펫 Lv 25 + 빙정석(유키시로 드롭) ×5 + 겨울 시즌 |

- 진화 시 이전 레벨/유대 유지
- 진화 불가능한 펫도 있음 (독립 종)
- 신수(★★★★★)는 진화가 아닌 퀘스트 전용 획득

## 펫 보유 & 관리

- **길드 펫 보유**: 초기 3마리, 확장 가능 (최대 10)
- **원정 동행**: 파티당 1마리
- **펫 소굴(獣舎)**: 미동행 펫 관리, 훈련, 부화
- 부화: 알을 펫 소굴에 배치 → 시간 경과 후 부화 (종류는 시드 기반)
