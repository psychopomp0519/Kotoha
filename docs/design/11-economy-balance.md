> 수치는 나중에 조정할 수 있다. 구조가 먼저다.

## 자원 순환 구조

### 주요 자원

| 자원 | 획득 | 소비 | 특성 |
|------|------|------|------|
| 금화(金貨) | 원정, 판매, 교역 | 모집, 시설, 강화, 제작 | 범용 화폐, 인플레이션 관리 필요 |
| 소재(素材) | 원정 드롭, 정원 | 제작 전반 | 등급별 분리, 용도 특화 |
| 경험치(経験値) | 원정, 훈련, 이벤트 | 레벨업 (자동 소비) | 모험가별 분리 |
| 곡옥(勾玉) | 환생 | 영구 강화 | 메타 화폐, 환생 전용 |

### 자원 흐름 밸런스

```
[유입] ──── 자원 풀 ──── [소비]

금화:
  유입: 원정(60%) + 판매(25%) + 이벤트(15%)
  소비: 시설(30%) + 모집(20%) + 제작(25%) + 강화(15%) + 기타(10%)

소재:
  유입: 원정 드롭(70%) + 정원(20%) + 교역(10%)
  소비: 장비 제작(40%) + 물약/요리(35%) + 부적(15%) + 기타(10%)
```

### 건전성 규칙

1. **모든 자원은 생산과 소비가 있어야 한다** (무한 축적 방지)
2. **상위 콘텐츠의 소비가 하위 콘텐츠의 생산을 초과** (진행 동기)
3. **환생은 자원 리셋** (인플레이션 자연 해소)
4. **오프라인 축적 상한** (방치 기간에 비례한 무한 축적 방지)

### 일일 경험치 추정

```
초반 (제1국, Lv 1~15):
  원정 5분 = 300틱, 전투 3~5회, 적 Lv 1~5
  원정 1회 XP: (3 × 15) + 조우 30 = ~75 XP
  방치 24시간: (86400 ÷ 300) × 75 = ~21,600 XP (상한 24시간 기준)
  → 오프라인 안전 루트 보정(조우 수 60~70%): ~13,000~15,000 XP/일
  능동 접속 시: 최적 루트(100% 조우) → ~21,600 XP/일
  회당 보상은 동일, 안전 루트로 조우 수만 감소

  → Lv 15 누적 ~9,200 XP
  → 실질 일일(방치): ~13,000 XP → Lv 15까지 약 1일 미만

  ※ Lv 15는 "도달 가능 레벨"이지 보스 공략 레벨이 아님
  ※ 보스 공략(Lv17~20)에는 장비, 편성, 시설 업그레이드가 병목 → 실질 3~5일
  ※ Lv 20 누적 ~5,800, Lv 17 누적 ~4,500 → 레벨 자체는 1~2일이면 도달
  ※ 진정한 병목: 고급 장비 제작(대장간 Lv3 + 소재 수집)에 2~3일 소요
```

## 금화 경제

### 금화 인플레이션 제어

| 단계 | 일 수입 (추정) | 주요 소비 | 밸런스 |
|------|---------------|-----------|--------|
| 초반 (1~3일) | 2,000~4,000 | 모집(200~500), 시설 Lv2(254) | 잉여 → 저축 |
| 초중반 (3~7일) | 4,000~7,000 | 시설 Lv3(467), 제작(300~600) | 잉여 |

| 후반 (15~30일) | 15,000~30,000 | 강화(5,000~15,000), 고급 모집(5,000) | 균형 |
| 엔드 (30일+) | 30,000~60,000 | 신기 제작(20,000+), 환생 준비 | 잉여→환생 리셋 |

### 금화 획득 증가 요인

- 깊은 깊이 원정 → 금화 드롭 증가 (깊이당 ×1.5)
- 상인 계통 모험가 → 금화 +10~30%
- 교역소 해금(제4국) → 잉여 소재 판매 가능
- 행운 장비/펫 → 금화 드롭 보너스

### 주요 금화 싱크

- 시설 업그레이드 (레벨 기하급수적: `비용 = 기본 × Lv^1.8 × 할인율`, 상세 `07-crafting-professions.md`)
- 장비 강화 (+6 이상 비용 급증)
- 고급 모험가 모집 (주점 특수 모집)
- 교역소 거래
- 펫 부화/훈련 비용

### 보스전 밸런스 검증 (고다이가에루 예시)

```
파티: 검사 Lv17 + 무녀 Lv15 + 시노비 Lv16 + 야마부시 Lv14
장비: 고급 카타나(+15 공격력), 고급 경갑(+10 방어)

■ 스탯 계산 (공식: 기준값 + (Lv-1) × 성장률)

검사 Lv17: STR = 14 + 16×3 = 62, END = 12 + 16×2 = 44
  물리공격 = 62 × 2.5 + 15 = 170
  최대 HP = 44 × 10 + 17 × 5 = 525

무녀 Lv15: SPI = 14 + 14×3 = 56, END = 10 + 14×1 = 24
  회복량 = 56 × 스킬배율1.0 × (1 + 대상SPI평균15 × 0.01)
         = 56 × 1.0 × 1.15 = 64 (치유의 기도, 파티 전체)
  최대 HP = 24 × 10 + 15 × 5 = 315

시노비 Lv16: SPD = 15 + 15×3 = 60, STR = 8 + 15×2 = 38
  물리공격 = 38 × 2.5 + 12 = 107
  최대 HP = (10 + 15×1.5) × 10 + 16×5 = 325 (END 기준값 10)

야마부시 Lv14: INT = 12 + 13×2.5 = 44.5, SPI = 13 + 13×2.5 = 45.5
  술법공격 = 44.5 × 2.5 + 10 = 121
  최대 HP = (8 + 13×1.5) × 10 + 14×5 = 275

■ 보스: 고다이가에루 HP 2000, 물리방어 30, 공격 40

■ 턴당 계산

파티 공격 (방어 차감 후):
  검사: 170×1.0 - 30×0.4 = 158 (기본 공격)
  시노비: 107×1.0 - 30×0.4 = 95
  야마부시: 121×1.0 - 30×0.35 = 110 (술법)
  무녀: 회복 턴 (공격 안 함)
  턴당 파티 데미지: ~363 (이상적)
  실전 (회피/미스/버프턴 감안 ×0.65): ~236

보스 공격:
  40 × 2회 = 80 → 전위 2명에 분산 (각 ~40 피해)
  무녀 회복 64 (파티 전체) → 넉넉히 상쇄

■ 예상 라운드: 2000 ÷ 236 ≈ 8.5라운드 (이상적 12~13)
  난수/페이즈 전환/광역기 감안: 15~20라운드

파티 총 HP: 525+315+325+275 = 1,440
보스 총 피해(20라운드): 80 × 20 = 1,600 (광역기 포함 ~2,000)
무녀 총 회복(20라운드): 64 × 18턴(회복) = 1,152
순 피해: 2,000 - 1,152 = 848 → 1,440 HP로 생존 가능 ✓

→ 30라운드 제한 내 클리어 가능 ✓
→ 힐러 없으면 ~12라운드에서 전멸 (힐러 필수 강조) ✓
→ 원소 상성 활용(목→토 ×1.5, 토→수 ×1.5) 시 ~14라운드 클리어 가능
```

## 밸런스 자동 테스트

### 테스트 시나리오 (Vitest)

```typescript
describe('Economy Balance', () => {
  it('1000틱 시뮬레이션에서 금화 인플레이션이 300% 미만', () => {
    const sim = runSimulation({ ticks: 1000, strategy: 'optimal' });
    expect(sim.goldInflation).toBeLessThan(3.0);
  });

  it('최적 플레이 시 제1국 보스 3~5일 내 도달', () => {
    const sim = runSimulation({ target: 'boss_1', strategy: 'optimal' });
    expect(sim.daysToReach).toBeGreaterThan(2);
    expect(sim.daysToReach).toBeLessThan(6);
  });

  it('방치 전용 플레이어도 7일 내 제1국 보스 도달', () => {
    const sim = runSimulation({ target: 'boss_1', strategy: 'idle_only' });
    expect(sim.daysToReach).toBeLessThan(8);
  });

  it('모든 자원에 싱크가 존재 (무한 축적 없음)', () => {
    const sim = runSimulation({ ticks: 100000, strategy: 'hoard' });
    for (const resource of sim.resources) {
      expect(resource.maxAccumulated).toBeLessThan(resource.softCap * 5);
    }
  });
});
```

## 밸런스 철학

1. **숫자 조정은 쉽게**: 모든 수치는 데이터 파일에서 관리, 코드 수정 없이 밸런스 패치
2. **체감 우선**: 수학적 최적보다 "느낌이 좋은" 수치
3. **길마아던 참고**: idleguildmaster.info의 실제 수치를 기준점으로 활용
4. **자동 테스트**: 밸런스 변경마다 시뮬레이션 실행
5. **방치 = 회당 동일 보상**: 전투 1회 보상에 차이 없음. 단 방치 원정은 안전 루트(조우 수 60~70%)로 시간당 수입 자연 감소
6. **능동 = 효율 + 고유 콘텐츠**: 최적 루트(100% 조우) + 도감 축적, 보스 도전, 이벤트 선택은 능동에서만
7. **원소 상성은 ×1.5/×0.7**: 약점을 찌르면 확실히 유리. 단, 모든 보스 약점 2개+ → 정답 원소 없음
8. **실패 = 정찰**: 보스 약화 없음. 대신 실패할수록 도감에 정보 축적. 성장해서 이기는 성취감
9. **24시간 방치 = 축적 상한 내 완전 보장**: 안전 루트로 꾸준히 성장. 능동은 더 빠를 뿐
