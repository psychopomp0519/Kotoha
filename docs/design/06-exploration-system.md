# 06 — Exploration System (원정 시스템)

> 길드의 존재 이유 — 요기에 잠식된 땅을 탐험하고, 세계의 비밀을 밝힌다.

---

## 원정 개요

원정은 코토하의 **핵심 콘텐츠 소비 루프**다. 파티를 편성하고 목적지에 파견하면, 모험가들이 자동으로 탐험하고 전투하고 전리품을 가지고 돌아온다.

---

## 원정 흐름

```
1. 편성: 파티 구성 (4명 + 소모품)
2. 목적지 선택: 지역 + 깊이 단계
3. 파견: 타이머 시작
4. 탐험 (자동): 조우 시퀀스 진행
5. 귀환: 결과 보고서 + 전리품 수령
```

---

## 목적지 구조

### 지역 (国)

- `02-world-setting.md`에 정의된 10개 지역
- 각 지역은 순차 해금 (이전 지역 보스 처치 필요)
- 미래 콘텐츠 업데이트로 추가 지역 확장 가능

### 깊이 단계

각 지역은 5단계의 깊이를 가진다.

| 깊이 | 명칭 | 소요 시간 | 조우 수 | 요괴 레벨 | 전리품 등급 |
|------|------|-----------|---------|-----------|-------------|
| 1 | 외곽(外縁) | 5~15분 | 3~5 | 기본 | 일반 |
| 2 | 중간(中間) | 30분~1시간 | 6~10 | 기본+5 | 일반~고급 |
| 3 | 심부(深部) | 1~3시간 | 10~15 | 기본+10 | 고급 |
| 4 | 최심부(最深部) | 3~6시간 | 15~20 | 기본+15 | 고급~희귀 |
| 5 | 보스(主) | 특수 | 보스 1체 | 보스급 | 희귀~전설 |

> 깊이 5(보스) 해금 조건:
> 1. 깊이 4 최소 3회 클리어 (지역 익숙도 확보)
> 2. 파티 평균 레벨 ≥ 지역 기준 레벨 (제1국: Lv12, 제2국: Lv28, 제3국: Lv42, ...)
> ※ 특정 아이템/원소/클래스는 요구하지 않음 — 어떤 파티든 도전 가능
> ※ 보스는 약해지지 않는다. 실패 시 보스 정보가 도감에 축적 → 전략 수립 지원
> ※ 보스 도전은 능동 플레이에서만 가능 (방치 중 보스 자동 도전 불가)

### 시간 계산

```
기준 틱: 깊이1=300, 깊이2=1800, 깊이3=5400, 깊이4=14400 (00-master-formulas.md 정의 원본)
실제 소요 틱 = 기준 틱 ÷ (1 + 파티 평균 SPD × 0.01)
```

> 위 테이블의 "5~15분" 등 범위 표기는 SPD에 따른 실소요 시간 범위.
> 예: 깊이 1 기준 300틱(5분), SPD 0 파티 = 5분, SPD 100 파티 = 300÷2 = 2.5분.
> "5~15분"은 반복 원정 시 조우 수/전투 시간 포함한 체감 범위 (기준 틱은 고정).

## 조우 시스템

원정 중 자동으로 발생하는 이벤트 단위.

### 조우 유형

| 유형 | 빈도 | 설명 |
|------|------|------|
| 전투 (戦闘) | 50~60% | 요괴와의 전투 |
| 발견 (発見) | 15~20% | 자원, 숨겨진 장소, 보물상자 |
| 함정 (罠) | 10~15% | 함정 → 감지/회피 판정 |
| 야영 (野営) | 5~10% | HP/기 부분 회복 |
| 이벤트 (出来事) | 5~10% | 시드 기반 특수 이벤트 |

### 조우 생성 규칙

```
조우 시퀀스 = seed_random(지역 시드 + 깊이 + 원정 횟수) → 조우 타입 배열
```

- 첫 조우는 항상 전투 (튜토리얼 제외)
- 마지막 조우는 전투 or 보스
- 연속 전투는 최대 3회까지 (3회 후 야영 or 발견 강제 삽입)
- 이벤트 조우는 `10-event-system.md`의 규칙에 따라 트리거

## 전투 조우 상세

### 적 편성

- 지역 + 깊이에 따른 요괴 풀에서 시드 기반 선택
- 적 수: 1~4체 (깊이가 깊을수록 다수 출현 확률↑)
- 엘리트 요괴: 10% 확률, 스탯 ×1.5 + 추가 드롭

### 요괴 데이터 예시 (제1국: 아사기리)

| 요괴 | 레벨 | HP | 원소 | 특수 |
|------|------|-----|------|------|
| 코타누키(小狸) | 1~3 | 30~50 | 토 | 변신으로 아이템 훔침 |
| 카파(河童) | 3~6 | 60~90 | 수 | 물가에서 STR +20% |
| 코다마(木霊) | 2~5 | 40~60 | 목 | 분열: HP 50% 이하 시 2체로 |
| 오니졸병(鬼卒) | 5~8 | 100~150 | 화 | 없음 (기본 전투원) |
| 히토다마(人魂) | 4~7 | 50~70 | 무 | 물리 내성 50% |
| **고다이가에루(보스)** | 15 | 2000 | 수/토 | 페이즈 전환, 전체 공격 |

## 발견 조우 상세

### 발견 유형

| 유형 | 설명 | 판정 | 보상 내용 |
|------|------|------|-----------|
| 자원 노드 | 약초, 광석, 목재 등 | 자동 채취 | 지역별 소재 1~3종 (광석, 약초, 목재, 식재료 등) |
| 보물상자 | 잠긴 상자 | 함정 체크 후 개봉 | 금화(50~500) + 장비 or 소모품 1개 (등급: 깊이 의존) |
| 숨겨진 장소 | 비밀 통로, NPC | INT 판정 | 추가 조우 진입, NPC 거래, 레시피 힌트, 이벤트 트리거 |
| 유물 | 특수 소재 | 자동 획득 | 제작 전용 소재, 퀘스트 아이템, 도감 수집품 |

### 자원 노드 지역별 드롭 풀

| 지역 | 주요 자원 노드 |
|------|----------------|
| 아사기리 | 약초, 철광석, 대나무, 쌀(논), 민물고기 |
| 쿠라야미다니 | 희귀약초, 영목, 광석, 텐구 깃털(낙하물) |
| 우미나리 | 산호, 진주, 소금, 해초, 생선 |
| 하나카게 | 비단, 향, 찻잎, 금분, 두루마리 |
| 유키시로 | 빙정석, 설련, 모피, 온천수 |
| 요미지 | 혼백석, 봉인 조각, 신기 파편 |

### 발견 품질

- 파티 내 INT가 높을수록 고품질 발견 확률↑
- 쇼쿠닌 계통의 "감정" 패시브: 발견 품질 +1등급
- 시노비 계통의 "탐색" 패시브: 숨겨진 장소 감지율 +25%

## 함정 조우 상세

### 함정 유형

| 함정 | 효과 (실패 시) | 감지 스탯 | 해제 스탯 |
|------|---------------|-----------|-----------|
| 낙석(落石) | 전위 HP 20% 피해 | INT | SPD (회피) |
| 독안개(毒霧) | 파티 전원 독 상태 | SPI | END (저항) |
| 요기 함정(妖気罠) | 파티 전원 봉인 2턴 | SPI | INT (해제) |
| 미혹(迷い) | 다음 조우까지 시간 ×2 | INT | — |
| 저주 부적(呪い札) | 랜덤 1명 저주 상태 | SPI | SPI (정화) |

### 함정 처리 흐름

```
함정 조우
  └→ 감지 판정: 파티 최고 감지 스탯 vs 함정 난이도
       ├→ 성공: 함정 발견 → 해제 판정
       │   ├→ 해제 성공: 무피해 통과 + 보너스 경험치
       │   └→ 해제 실패: 경감된 효과 (50%)
       └→ 실패: 함정 발동 → 전체 효과
```

## 야영 조우

- 파티가 잠시 쉬며 회복
- HP 회복: 최대 HP의 20~30%
- 기 회복: 최대 기의 30~40%
- 음식 소모: 장착된 음식 1개 사용 → 추가 효과
  - 음식 없으면 기본 회복만
- 야영 중 이벤트 발생 가능 (캠프파이어 대화 등)

## 전리품 시스템

### 드롭 테이블 구조

각 요괴는 드롭 테이블을 가진다.

```
요괴 드롭 = [
  { item: "오니의 뿔", chance: 40%, quantity: 1~2 },
  { item: "금화", chance: 80%, quantity: 10~30 },
  { item: "마석", chance: 10%, quantity: 1 },
  { item: "오니의 철곤봉(장비)", chance: 2%, quantity: 1 }
]
```

### 드롭률 보정

| 보정 요인 | 효과 |
|-----------|------|
| 능동/방치 | 드롭률 동일 (격차 없음) |
| 탐욕 특성 | 드롭 수량 +20% |
| 행운 장비 | 드롭률 +N% |
| 깊이 보너스 | 깊은 깊이일수록 희귀 드롭↑ |
| 첫 클리어 보너스 | 해당 깊이 첫 클리어 시 확정 보너스 드롭 |

### 전리품 등급

| 등급 | 색상 | 출현 조건 |
|------|------|-----------|
| 일반(普通) | 흰색 | 어디서나 |
| 고급(上等) | 녹색 | 깊이 2+ |
| 희귀(稀少) | 청색 | 깊이 3+, 엘리트/보스 |
| 전설(伝説) | 보라색 | 보스, 특수 조건 |
| 신기(神器) | 금색 | 환생 콘텐츠, 최종 보스 |

## 동시 원정

### 원정 슬롯

- 초기: 1슬롯 (1개 파티 파견 가능)
- 길드 확장(시설 업그레이드)으로 최대 4슬롯
- 2번째 슬롯: 제2국 해금 시 확장 가능
- 각 슬롯은 독립적 (다른 지역/깊이 가능)

### 요기 침식 (원정 중)

원정 중 모험가는 지역의 요기에 노출된다. 침식 축적 공식:
→ 상세: `03-adventurer-system.md` "침식 축적 공식" 참조

- 깊은 깊이일수록 요기 농도 가중 (깊이 × 1.2 배율)
- 퇴마 부적 장착 시 침식 축적 -30%
- 정화 스킬 보유 모험가가 파티에 있으면 전원 축적 -15%

### 원정 자동 반복

원정 완료 시 같은 목적지·같은 파티로 **자동 재파견**된다.

- 자동 반복 ON/OFF: 원정 슬롯 화면에서 토글
- 소모품은 매 원정마다 소비, 소진 시 소모품 없이 계속
- 모험가 HP 30% 미만 시 자동 귀환 → 회복 후 재파견
- 보스(깊이 5)는 자동 반복 대상에서 **제외**
- 오프라인 중에도 자동 반복 진행 → 부재 중 보고서에서 "×N회 완료"로 표시

### 제한

- 같은 모험가가 동시에 2개 원정에 참여 불가
- 같은 지역 + 같은 깊이에 2개 파티 파견 불가
- 부상/침식 중인 모험가는 원정 불가

## 구현 참고

```typescript
interface Expedition {
  id: string;
  partyIds: string[];          // 모험가 ID 4명
  region: RegionId;
  depth: 1 | 2 | 3 | 4 | 5;
  startTick: number;
  estimatedEndTick: number;
  consumables: {
    food?: ItemId;
    potion?: ItemId;
    talisman?: ItemId;
  };
  encounters: Encounter[];      // 조우 시퀀스 (사전 생성)
  currentEncounter: number;     // 현재 진행 중인 조우 인덱스
  status: 'preparing' | 'active' | 'returning' | 'completed';
  result?: ExpeditionResult;
}

interface Encounter {
  type: 'combat' | 'discovery' | 'trap' | 'camp' | 'event';
  data: CombatEncounter | DiscoveryData | TrapData | CampData | EventId;
  resolved: boolean;
  result?: EncounterResult;
}

interface ExpeditionResult {
  totalCombats: number;
  wins: number;
  losses: number;
  expGained: number;
  goldGained: number;
  itemsGained: { itemId: ItemId; quantity: number }[];
  adventurerStates: {
    id: string;
    hpPercent: number;
    corruption: number;
    expGained: number;
  }[];
  eventsTriggered: EventId[];
  log: CombatLogEntry[];       // 축약 가능
}
```
