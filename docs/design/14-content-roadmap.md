## 콘텐츠 제작 우선순위

```
높음 (게임이 돌아가려면 필수):
  요괴 데이터, 클래스 트리, 기본 장비, 기본 소재, 레시피

중간 (게임을 재미있게 만드는 것):
  이벤트, 연쇄 이벤트, 펫, 세트 장비, 칭호

낮음 (폴리시):
  사운드, 업적, 히든 콘텐츠, 추가 지역
```
