# 12 — UI/UX Specification (UI/UX 사양)

> 와시 종이 위에 먹으로 쓴 듯한, 여백이 말하는 인터페이스.

---

## 디자인 원칙

1. **텍스트가 주인공**: UI는 텍스트를 돋보이게 하는 프레임
2. **여백 활용**: 빈 공간은 낭비가 아니라 디자인
3. **일본 전통 미학**: 와시(和紙) 질감, 먹(墨) 색감, 절제된 문양
4. **웹 네이티브**: 모바일 포트가 아닌, 웹에서 태어난 UI
5. **접근성**: 키보드 네비게이션, 스크린 리더 호환

## 화면 구조

### 메인 레이아웃

```
┌─────────────────────────────────────────────┐
│  ≡  코토하야(コトハ屋)          금화: 1,234  │  ← 상단 바
├──────────┬──────────────────────────────────┤
│          │                                    │
│  길드    │         메인 콘텐츠 영역           │
│  원정    │                                    │
│  시설    │    (선택된 탭에 따라 변경)          │
│  모험가  │                                    │
│  제작    │                                    │
│  도감    │                                    │
│  설정    │                                    │
│          │                                    │
├──────────┴──────────────────────────────────┤
│  [이벤트 알림] 여우의 은혜 — 선택 대기 중     │  ← 하단 알림
└─────────────────────────────────────────────┘
```

### 반응형

- **데스크톱 (1024px+)**: 사이드바 + 메인 영역 (위 레이아웃)
- **태블릿 (768~1023px)**: 하단 탭 바 + 전체 메인 영역
- **모바일 (767px-)**: 하단 탭 바 + 전체 메인 영역, 폰트 축소

## 시각적 진행감 (텍스트 기반)

텍스트 게임에서도 "화면이 변했다"는 느낌을 줄 수 있다:

### 길드 묘사 변화

메인 화면 상단의 길드 묘사가 진행도에 따라 변한다:

| 진행도 | 묘사 |
|--------|------|
| 시작 | `허름한 오두막. 비가 새는 지붕 아래, 세 명의 모험가가 모였다.` |
| 제2국 | `목조 건물에 간판이 걸렸다. 'コトハ屋'. 대장간에서 쇠 두드리는 소리가 난다.` |
| 제5국 | `2층짜리 길드 건물. 모험가들의 웃음소리가 주점에서 흘러나온다.` |
| 제8국 | `마을에서 가장 큰 건물. 지나가는 사람들이 고개를 숙인다.` |
| 이면 돌입 | `전설의 길드. 벽에 걸린 수십 개의 칼이 지나온 세월을 말한다.` |

### 클래스 티어 표시

모험가 이름 옆에 티어를 시각적으로 표현:

```
야요이(浪人)       — Tier 1 (이름만)
야요이(剣豪) ★     — Tier 2 (★ 1개)
야요이(剣鬼) ★★    — Tier 3 (★ 2개)
야요이(天下無双) ★★★ — Tier 4 (★ 3개)
```

### 장비 등급 색상

텍스트 색상으로 등급 구분 (CSS 변수 활용):
- 일반: 기본색(먹)
- 고급: `--rarity-uncommon` (녹색)
- 희귀: `--rarity-rare` (청색)
- 전설: `--rarity-legendary` (보라색)
- 신기: `--rarity-divine` (금색, 글자 주변 미세한 glow)

### 시즌 배경 변화

게임 내 계절에 따라 배경 CSS 변수가 변한다:
- 봄: 연분홍 톤, 벚꽃 문양 테두리
- 여름: 짙은 녹색 톤, 풀벌레 앰비언트
- 가을: 적갈색 톤, 단풍 문양
- 겨울: 백색+청색 톤, 눈 결정 문양

## 애니메이션 & 전환

### 원칙

- **CSS만 사용** — Canvas/JS 애니메이션 최소화
- 빠르고 가벼운 전환 (200~400ms)
- 먹이 스며드는 듯한 페이드 인

### 전환 효과

| 상황 | 효과 |
|------|------|
| 화면 전환 | 페이드 (200ms) |
| 이벤트 등장 | 먹 번짐 효과 (ink-wash fade, 400ms) |
| 수치 변경 | 부드러운 카운트업 (300ms) |
| 새 아이템 획득 | 잠깐 빛남 (200ms glow) |
| 레벨업 | 텍스트 강조 + 짧은 진동 |
| 보스 등장 | 화면 어두워짐 + 이름 페이드인 |

## 세이브 시스템

- **단일 세이브**: 세이브 슬롯 1개. 복수 세이브 불가.
- **자동 저장**: 모든 의사결정 후 즉시 자동 저장 (IndexedDB)
- **백업 내보내기**: 설정 메뉴에서 JSON 파일 다운로드 (수동 백업용)
- **백업 가져오기**: 설정 메뉴에서 JSON 업로드
- **이중 저장**: IndexedDB(주) + localStorage(비상 백업)
- **버전 관리**: 세이브에 GDD 버전 포함, 업데이트 시 자동 마이그레이션

> 환생은 세이브 내 프레스티지 레이어. 새 세이브가 아님.

## 접근성

- **키보드 네비게이션**: Tab으로 모든 인터랙티브 요소 접근
- **스크린 리더**: aria-label, 의미 있는 HTML 구조
- **고대비 모드**: CSS 변수로 색상 테마 전환
- **폰트 크기 조절**: 브라우저 줌 대응 (rem 단위)
- **색맹 대응**: 등급 표시에 색상만 의존하지 않음 (아이콘/텍스트 병행)
