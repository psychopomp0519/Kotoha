# 13 — Narrative Design (서사 디자인)

> 잘 쓰인 문장 한 줄이 화려한 그래픽보다 깊은 인상을 남긴다.

---

## 문체 원칙

### 톤

- **무시시 + 나츠메 우인장**: 잔잔한 서정 속의 기이함
- 애니메이션 코미디 톤 **절대 금지**
- 감정을 직접 설명하지 않는다 — 행동과 묘사로 드러낸다
- 유머가 있되, 웃기려고 하지 않는다

### 기본 규칙

1. **짧게**: 이벤트 서술 100~300자, 전투 로그 1~2문장
2. **감각적으로**: 시각, 청각, 후각, 촉각 중 하나 이상 포함
3. **구체적으로**: "좋은 것을 얻었다" (X) → "따뜻한 기운이 감도는 부적" (O)
4. **여운 남기기**: 모든 것을 설명하지 않는다 — 빈 공간은 상상으로 채워진다
5. **3인칭 관찰자**: 길드 마스터의 시점. "당신"이 아닌 "~가", "~는"

## 텍스트 유형별 가이드

### 이벤트 서술

```
[좋은 예]
비가 그친 뒤, 길드 문 앞에 하얀 여우 한 마리가 앉아 있었다.
꼬리가 셋이었다. 젖은 털에서 벚꽃 향이 났다.

[나쁜 예]
갑자기 신비한 흰 여우가 나타났습니다! 꼬리가 3개나 있는 신비로운 여우입니다!
이것은 분명 특별한 이벤트일 것입니다!
```

### 전투 로그

```
[좋은 예]
야요이(浪人)가 오니 대장의 틈을 노려 일도양단을 날렸다 — 342 피해.
카에데(巫)가 조용히 기도를 올렸다 — 파티 전원 HP 45 회복.

[나쁜 예]
야요이님이 강력한 공격 스킬을 사용합니다! 오니 대장에게 342의 데미지!
카에데님이 힐 스킬을 사용합니다! 파티 전원 45 HP 회복!
```

### 선택지

```
[좋은 예]
· 여우를 따라간다
· 음식을 건넨다
· 모른 척 지나간다

[나쁜 예]
· [전투] 여우를 공격한다! (STR 체크)
· [외교] 여우와 대화를 시도한다 (INT 체크, 보상: 희귀 아이템)
· [무시] 그냥 지나간다 (효과 없음)
```

선택지는 결과를 **예측할 수 없게** 써야 한다. 정답이 보이면 선택의 의미가 없다.

### 시설/시스템 설명

```
[좋은 예]
카지바(鍛冶場) — 대장간
쇠를 달구는 열기와 망치 소리가 길드의 아침을 깨운다.

[나쁜 예]
대장간 시설입니다. 여기서 무기와 방어구를 제작할 수 있습니다.
레벨업하면 더 높은 등급의 장비를 만들 수 있습니다.
```

## 언어 규칙

### 한국어-일본어 병기

- 고유명사 첫 등장 시: `한국어(일본어)` 형식
  - 예: `아사기리(朝霧)`, `검사(剣士)`, `야요이(弥生)`
- 이후에는 한국어만 사용 (반복 불필요)
- UI 레이블은 한국어 메인, 일본어 작게 표시

### 모험가 이름

- 일본식 성+이름
- 성은 자연물 기반: 사쿠라(桜), 아오야마(青山), 시라카와(白川)
- 이름은 계절/자연: 하루(春), 유키(雪), 카에데(楓), 렌(蓮)
- 케모노 계통은 동물 관련 이름도 가능: 코가네(黄金), 긴(銀)

### 요괴 이름

- 실제 일본 요괴 이름 사용 (가능한 한 원어 유지)
- 오리지널 요괴는 일본어 조어 규칙 따름
- 보스급은 존칭/수식어 부여: 오오텐구(大天狗), 교쿠코(玉狐)

## 스토리 라인

### 메인 스토리 구조

```
도입: 작은 길드, 큰 세계
  └→ 제1장: 아사기리의 이변 (제1국: 아사기리)
       "요기가 짙어지고 있다. 마을을 지키려면 우리가 나서야 한다."
  └→ 제2장: 산의 경고 (제2국: 쿠라야미다니)
       "텐구가 말한다 — 봉인이 약해지고 있다고."
  └→ 제3장: 바다 너머의 그림자 (제3국: 우미나리)
       "바다 밑에서 올라오는 것은 요괴만이 아니었다."
  └→ 제4장: 꽃 그림자 속의 음모 (제4국: 하나카게)
       "성주가 변했다. 아니, 바뀌었다."
  └→ 제5장: 겨울의 끝 (제5국: 유키시로)
       "봉인된 카미의 잔영이 말한다 — 진실을 찾으라."
  └→ 제6장: 불꽃의 대장간 (제6국: 카구츠치산)
       "화산의 심장에서, 신을 죽인 불의 기억이 깨어난다."
  └→ 제7장: 거미의 미궁 (제7국: 츠치구모노스)
       "지하 깊은 곳에 잊힌 역사가 거미줄에 얽혀 있다."
  └→ 제8장: 하늘의 문 (제8국: 아마노이와토)
       "닫힌 바위문 너머, 카미들이 잠든 진짜 이유가 있다."
  └→ 제9장: 영원의 가을 (제9국: 토코요)
       "시간이 멈춘 숲에서, 대봉인의 열쇠를 찾는다."
  └→ 최종장: 황천의 길 (제10국: 요미지)
       "대봉인의 진실. 그리고 선택."
```

### 스토리 전달 방식

- **텍스트 전용** — 컷씬, 동영상 없음
- 이벤트 시스템으로 스토리 비트 전달
- 보스 격파 후 특별 스토리 이벤트 (강제 발생)
- 연쇄 이벤트로 서브 스토리 라인

### 엔딩 분기

스토리 최종 선택에 따라 2~3개 엔딩.
플래그 누적에 따라 결정 — "어떤 길드를 운영해왔는가"가 반영됨.

## 부재 중 보고서 문체

방치 후 복귀 시 보고서도 분위기 있게.

```
[좋은 예]
═══════════════════════════
  부재 중 보고서
  밤이 지나고 아침이 왔습니다.
═══════════════════════════

길드가 잠든 사이, 세계는 계속 움직였습니다.

▶ 야요이의 원정대가 아사기리 심부에서 돌아왔습니다.
  오니 졸병 8마리를 쓰러뜨리고, 카파의 갑옷을 가져왔습니다.
  야요이는 자랑스러운 듯 검을 닦고 있습니다.

▶ 카에데가 도장에서 수련을 마쳤습니다.
  조용히 새 기도문을 익혔습니다. (Lv 23 → 25)

▶ 대장간에서 철검이 2자루 완성되었습니다.
  아직 따뜻합니다.
```

## 사운드 디자인 메모 (후순위)

텍스트가 주인공이지만, 소리가 분위기를 완성한다.

| 상황 | 사운드 |
|------|--------|
| 길드 메인 화면 | 새소리, 바람, 먼 곳의 종소리 |
| 원정 중 | 발걸음, 풀벌레, 물소리 (지역별 차등) |
| 전투 | 칼 부딪히는 소리, 주문 읊는 소리 |
| 이벤트 | 풍경 소리, 짧은 효과음 |
| 보스전 | 낮은 북소리, 긴장감 있는 앰비언트 |
| 제작 완료 | 망치 소리, "딩" |
| 레벨업 | 짧은 종소리 |
