## 대장간 (鍛冶場)

### 기능

- **무기 제작**: 소재 + 금화 → 무기
- **방어구 제작**: 소재 + 금화 → 방어구
- **장비 강화**: 장비 + 강화석 → 스탯 증가
- **장비 분해**: 장비 → 소재 회수 (50%)
- **수리**: 내구도 회복

### 업그레이드 (레벨 1~10)

| 레벨 | 효과 |
|------|------|
| 1 | 일반 장비 제작 가능 |
| 3 | 고급 장비 제작 가능, 강화 +3까지 |
| 5 | 희귀 장비 제작 가능, 강화 +5까지 |
| 7 | 전설 장비 제작 가능, 강화 +7까지 |
| 10 | 신기급 제작 가능 (소재 필요), 강화 +10 |

### 제작 시간

```
제작 시간(틱) = 기본 시간 × 등급 배율 ÷ (1 + 대장간 Lv × 0.1)

기본 시간: 300틱 (5분)
등급 배율: 일반 ×1, 고급 ×3, 희귀 ×8, 전설 ×20, 신기 ×50
```

### 제작 품질

```
품질 판정 = 랜덤(0~100) + 제작자 INT × 0.5 + 대장간 Lv × 3 + 소재 품질 보정

소재 품질 보정 (사용 소재 중 최저 등급 기준):
  일반 = 0, 고급 = +5, 희귀 = +10, 전설 = +15, 신기 = +20

품질 결과:
  0~30:  실패작 (스탯 -20%)
  31~60: 보통
  61~80: 양품 (스탯 +10%)
  81~95: 명품 (스탯 +20%, 추가 효과 1개)
  96+:   걸작 (스탯 +30%, 추가 효과 2개, 이름 부여)
```

쇼쿠닌 계통 모험가가 제작 지원 시 품질 보너스 +15~30.

| 회복약(中) | 약초 ×3 + 이슬 ×1 | HP 60% 회복 |
| 회복약(大) | 희귀약초 ×2 + 영수 ×1 | HP 100% 회복 |
| 해독약 | 약초 ×2 + 독버섯 ×1 | 독/맹독 해제 |

| 속도의 비약 | 텐구 깃털 ×1 + 이슬 ×2 | SPD +15% (전투 3턴) |
| 지혜의 비약 | 영목 껍질 ×1 + 향 ×1 | INT +15% (전투 3턴) |
| 철벽의 비약 | 거북 등껍질 ×1 + 광석 ×2 | END +15% (전투 3턴) |

### 조합 실험

- 레시피에 없는 소재 조합으로 **신규 물약 발견** 가능
- 실험 결과는 시드 기반 결정 → 같은 조합은 같은 결과
- 성공 시 레시피에 영구 등록
- 실패 시 소재 소멸 + 약간의 경험치

## 도장 (道場)

### 기능

- **자동 훈련**: 모험가를 배치하면 오프라인에서도 경험치 축적
- **전직**: 조건 충족 시 클래스 변경 수행
- **스킬 수련**: 특정 스킬의 숙련도 올리기
- **모의전**: 길드 내 모험가끼리 모의 전투 (유대 경험치 보너스)

### 훈련 효율

```
훈련 경험치/틱 = 도장 Lv × 2 × (1 + 배치된 모험가 수 × 0.1)
```

도장 Lv 5, 모험가 3명 배치 시: 5 × 2 × 1.3 = 13 경험치/틱 (각각)

### 업그레이드

| 레벨 | 효과 |
|------|------|
| 1 | 배치 2명, 기본 훈련 |
| 3 | 배치 3명, 전직 가능 |
| 5 | 배치 4명, 스킬 수련 가능 |
| 7 | 배치 5명, 모의전 가능 |
| 10 | 배치 6명, 전직 비용 -30% |

## 다실 (茶室)

### 기능

- **사기 회복**: 모험가 배치 → 사기 회복 (+20/시간)
- **유대 이벤트**: 2명 이상 배치 시 유대 포인트 축적
- **특수 대화**: 특정 조합 배치 시 전용 이벤트 발생
- **차 종류**: 다른 차를 우리면 추가 효과

| 차 | 소재 | 효과 |

| 녹차(緑茶) | 찻잎 ×2 | 사기 회복 기본 |

| 호지차(ほうじ茶) | 볶은 찻잎 ×2 | 사기 회복 + 상태이상 해제 |

## 자원 체인 다이어그램

```
[원정 드롭]
  ├──→ 요괴 소재 (뿔, 깃털, 가죽 등) ──→ [대장간] ──→ 무기/방어구 ──→ 모험가 장착
  ├──→ 광석/금속 ──→ [대장간] (보조 소재)
  ├──→ 약초/영물 ──→ [약제실] ──→ 물약/해독제 ──→ 원정 소모품
  ├──→ 식재료 (고기, 생선, 달걀) ──→ [주방] ──→ 요리 ──→ 원정 버프
  ├──→ 정화 소재 (신수, 향, 봉인석) ──→ [부적방] ──→ 오후다 ──→ 원정 보호
  ├──→ 영물 (영목, 영초) ──→ [부적방] + [약제실] (고급 재료)
  ├──→ 보석/귀금속 (금분, 산호, 진주) ──→ [대장간] 장신구 + [교역소] 판매
  ├──→ 와시(종이)/먹 ──→ [부적방] (기본 소재) + [서재] (스크롤)
  └──→ 금화 ──→ 시설 업그레이드 / 모집 / 강화 / 교역

[정원]
  ├──→ 약초/희귀약초/봉황초 ──→ [약제실]
  ├──→ 쌀/야채/과일 ──→ [주방]
  ├──→ 찻잎/벚꽃/영초 ──→ [다실]
  └──→ 비료 사용 가능 (원정 드롭에서 획득)

[교역소] (제4국 해금)
  ├──→ 잉여 소재 판매 ──→ 금화
  ├──→ 소재 상호 교환 (비율: 3:1 동급, 10:1 상위)
  └──→ 특수 소재 구매 (소금, 간장, 기름 등 비전투 소재)

[다실]
  └──→ 찻잎 소비 ──→ 사기 회복 + 유대 포인트

[펫 소굴]
  └──→ 포획 부적(부적방) + 먹이(주방/정원) ──→ 펫 관리
```

## 시설 업그레이드 비용 기준

```
업그레이드 비용 = floor(기본 비용 × (레벨 ^ 1.8) × 할인율)

할인율: Lv 1~3 → ×0.6 (초반 할인), Lv 4+ → ×1.0

기본 비용: 시설마다 다름 (80~150 금화)
추가 소재 필요: 레벨 5+ → 고급 소재, 레벨 8+ → 희귀 소재
```

| 시설 | 기본 | Lv2 | Lv3 | Lv4 | Lv5 | Lv7 | Lv10 | Lv2→3 합계 |
|------|------|-----|-----|-----|------|------|------|-----------|
| 대장간 | 150 | 313 | 650 | 1,819 | 2,718 | 4,970 | 9,464 | 963 |
| 약제실 | 120 | 251 | 520 | 1,455 | 2,174 | 3,976 | 7,572 | 771 |
| 주방 | 80 | 167 | 347 | 970 | 1,450 | 2,650 | 5,048 | 514 |
| 도장 | 150 | 313 | 650 | 1,819 | 2,718 | 4,970 | 9,464 | 963 |
| 기타 | 80~150 | 비례 | 비례 | 비례 | 비례 | 비례 | 비례 | 비례 |

> 검증: 대장간 Lv2 = floor(150 × 2^1.8 × 0.6) = floor(150 × 3.482 × 0.6) = floor(313.4) = 313 ✓
> 검증: 대장간 Lv5 = floor(150 × 5^1.8 × 1.0) = floor(150 × 18.12) = floor(2718) = 2,718 ✓
> Lv 2→3 합계 (대장간): 313 + 650 = 963 금화
> 초반 3~5일 수입(6,000~20,000)으로 충분히 감당 가능 (^1.8로 후반 싱크 강화)
