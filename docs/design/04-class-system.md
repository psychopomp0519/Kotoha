# 04 — Class System (클래스 시스템)

> 6개의 뿌리에서 200개의 가지가 뻗어나간다.

---

## 개요

모든 모험가는 6개 기본 계통 중 하나로 시작하며, 7단계에 걸쳐 전직한다.
길드마스터 아이들 던전의 9단계 70+ 클래스를 참고하되, 6계통 × 깊은 분기로 **기본 트리 ~234 클래스**를 목표한다. (히든/이벤트 전용 포함 시 ~296)

### 전직 구조

```
Tier 0 (기본)  → Lv 1  | 6 클래스
Tier 1 (상급)  → Lv 10 | 18 클래스 (계통당 3)
Tier 2 (숙련)  → Lv 25 | 36 클래스 (T1당 2)
Tier 3 (달인)  → Lv 45 | 72 클래스 (T2당 2)
Tier 4 (명인)  → Lv 65 | ~60 클래스 (T3당 0~2, 선택적 분기)
Tier 5 (전설)  → Lv 85 | ~30 클래스 (수렴형, 특수 조건)
Tier 6 (신화)  → Lv 100 | ~12 클래스 (계통당 2, 환생 필수)
```

**기본 트리 ~234 클래스** (히든 클래스 ~30 + 이벤트 전용 ~32 포함 시 총 ~296)
(구현은 단계적: Phase 3에서 T0~T3, Phase 4에서 T4, Phase 8에서 T5~T6 + 히든/이벤트)

### 전직 조건 유형

| 조건 유형 | 설명 | 예시 |
|-----------|------|------|
| 레벨 | 최소 레벨 도달 | Lv 25 |
| 스탯 | 특정 스탯 이상 | STR ≥ 40 |
| 아이템 | 전직 소재 보유 | 텐구의 깃털 ×5 |
| 이벤트 | 특정 이벤트 클리어 | "검의 시련" 완료 |
| 처치 | 특정 요괴 처치 수 | 오니 100체 |
| 지역 | 특정 지역 도달/클리어 | 제3국 클리어 |
| 환생 | 환생 횟수 | 환생 2회+ |
| 유대 | 유대 단계 조건 | 무이(4단계) 2쌍+ |
| 침식 | 요기 침식 경험 | 침식 3단계 도달 |
| 제작 | 제작 관련 실적 | 전설 장비 3개 제작 |
| 금화 | 금화 보유/사용 | 금화 50,000 보유 |
| 복합 | 위 조건들의 조합 | Lv85 + STR≥80 + 보스 20체 |

## 크로스 계통 시스템

### 부직업 (副職)

- Tier 3 이상 모험가는 **부직업**을 1개 장착 가능
- 부직업은 다른 계통의 Tier 0~1 스킬을 사용 가능하게 함
- 부직업 스킬 효과: 본직업 대비 60%
- Tier 5 이상: 부직업 2개 장착 가능
- 조건: 해당 계통의 모험가가 길드에 Tier 2 이상 1명 존재

### 합체기 조합 (유대 4단계)
