## 생성 규칙

```typescript
function generateName(seed: number, baseClass: BaseClass): AdventurerName {
  const rng = seedRandom(seed);
  const familyIdx = floor(rng() * FAMILY_NAMES.length);
  const givenIdx = floor(rng() * GIVEN_NAMES.length);

  return {
    family: FAMILY_NAMES[familyIdx].ko,
    given: GIVEN_NAMES[givenIdx].ko,
    familyJp: FAMILY_NAMES[familyIdx].jp,
    givenJp: FAMILY_NAMES[givenIdx].kanji,
  };
}
```

### 제한

- 같은 길드 내 동명이인 불가 (충돌 시 givenIdx++)
- 튜토리얼 3인 고정: 야요이(검사), 카에데(무녀), 렌(시노비)
