## 지역 해금 순서

```
제1국 아사기리(朝霧) ──[보스 격파]──→ 제2국 쿠라야미다니(暗闇谷)
  ──[보스]──→ 제3국 우미나리(海鳴)
    ──[보스]──→ 제4국 하나카게(花影)
      ──[보스]──→ 제5국 유키시로(雪城)
        ──[보스]──→ 제6국 카구츠치산(火具土山)
          ──[보스]──→ 제7국 츠치구모노스(土蜘蛛の巣)
            ──[보스]──→ 제8국 아마노이와토(天岩戸)
              ──[보스]──→ 제9국 토코요(常世)
                ──[보스]──→ 제10국 요미지(黄泉路)
```

```
조우 시퀀스 (고정, 시드 무시):
1. 전투: 코타누키(小狸) × 1마리
2. 발견: 약초밭 (약초 ×3 확정)
3. 전투: 오니졸병(鬼卒) × 1마리

보상: XP 75, 금화 30, 오니의뿔 ×1, 약초 ×3
```
