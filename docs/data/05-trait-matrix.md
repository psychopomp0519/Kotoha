## 적용 규칙

1. 시너지/마찰은 **파티 단위**로 적용 (길드 전체가 아님)
2. 같은 특성 2명 이상: 효과 **중복 불가** (최고치 1명만)
3. 시너지와 마찰이 동시에 충족되면 **둘 다 적용**
4. 탐험 효과(함정 감지, 발견 확률 등)는 **파티 내 최고치 1명** 기준
5. 모집 시 특성은 시드 기반 랜덤 2~3개 부여, 변경 불가
6. 은퇴 시 특성 정보는 명예의 전당에 기록
