## 1. 스탯 시스템

### 기본 스탯 성장

```
현재 스탯 = 기준값 + (Lv - 1) × 성장률
```

### 계통별 전체 성장률 (합계 8.0/Lv)

| 계통 | STR | SPD | INT | SPI | END |
|------|-----|-----|-----|-----|-----|
| 검사 | 3.0 | 1.5 | 0.5 | 1.0 | 2.0 |
| 무녀 | 0.5 | 1.0 | 2.5 | 3.0 | 1.0 |
| 시노비 | 2.0 | 3.0 | 1.5 | 0.5 | 1.0 |
| 야마부시 | 1.0 | 0.5 | 2.5 | 2.5 | 1.5 |
| 쇼쿠닌 | 2.0 | 1.0 | 3.0 | 0.5 | 1.5 |
| 케모노 | 2.5 | 2.5 | 0.5 | 1.5 | 1.0 |

### 계통별 기준 스탯 (Lv1)

| 계통 | STR | SPD | INT | SPI | END | 합계 |
|------|-----|-----|-----|-----|-----|------|
| 검사 | 14 | 10 | 6 | 8 | 12 | 50 |
| 무녀 | 5 | 8 | 13 | 14 | 10 | 50 |
| 시노비 | 8 | 15 | 10 | 7 | 10 | 50 |
| 야마부시 | 10 | 7 | 12 | 13 | 8 | 50 |
| 쇼쿠닌 | 12 | 6 | 14 | 8 | 10 | 50 |
| 케모노 | 13 | 12 | 5 | 9 | 11 | 50 |

### 파생 스탯

| 파생 스탯 | 공식 |
|-----------|------|
| 최대 HP | END × 10 + Lv × 5 |
| 물리 공격 | STR × 2.5 + 무기 공격력 |
| 술법 공격 | INT × 2.5 + 무기 술법력 |
| 물리 방어 | END × 1.5 + 방어구 방어력 |
| 술법 방어 | SPI × 1.5 + 방어구 술법방어 |
| 행동 속도 | SPD × 1 + 장비 보정 |
| 회피율 | SPD × 0.5% (상한 30%) |
| 기 최대치 | SPI × 5 |
| 기 충전량 | SPI × 0.3 / 턴 |
| 크리티컬률 | 5% + SPD × 0.2% + 장비 보정 (상한 50%) |

## 2. 경험치 시스템

```
필요 경험치: 아래 보간 테이블이 정의 원본 (권위값)
※ 근사 공식 floor(18 × Lv^1.6)은 Lv 10 부근에서만 정확
※ 고레벨로 갈수록 괴리 증가 (Lv 99: 공식=28,072, 실제=37,800)
※ 구현 시 테이블 보간 사용. 공식은 참고용.

보간 키포인트:
  Lv 1→2:     150  (고정)
  Lv 5→6:     251
  Lv 10→11:   716
  Lv 15→16:   1,330
  Lv 25→26:   3,380
  Lv 45→46:   9,370
  Lv 65→66:   17,900
  Lv 85→86:   28,440
  Lv 99→100:  37,800
  
  누적: Lv15=9,200 / Lv50=155,000 / Lv100=1,100,000

키포인트 사이 레벨은 선형 보간:
  xpRequired(lv) = lerp(lower_key, upper_key, lv)

| 조우 클리어 | rand(30, 150) |

### 무기/방어구 스탯 스케일 정의

정성적 표현 → 수치 변환 (base_stat_bonus, 일반 등급 Lv1 기준):

| 표기 | 값 |
|------|-----|
| 最高 | 6 |
| 高 | 4 |
| 中 | 3 |
| 低 | 2 |
| 微 | 1 |
| -低 | -1 |
| -中 | -2 |

### 장비 스탯 스케일링 공식

```
최종 스탯 보너스 = base_stat_bonus × 등급배율 × (1 + (장비Lv - 1) × 0.1)
```

## 4. 전투 공식

### 데미지

```
물리 기본 = (공격자 물리공격 × 스킬배율) - (대상 물리방어 × 0.4)
술법 기본 = (공격자 술법공격 × 스킬배율) - (대상 술법방어 × 0.35)
최종 = 기본 × 원소배율 × 크리배율 × rand(0.9, 1.1)
최소 = 1
```

### 회복

```
회복량 = 시전자 SPI × 스킬배율 × (1 + 대상 SPI × 0.01)
```

### 스킬 등급

| 등급 | 배율 | 기 소비 |
|------|------|---------|
| 기본 | 1.0 | 0 |
| 초급 | 1.5 | 10 |
| 중급 | 2.0 | 25 |
| 상급 | 3.0 | 50 |
| 극의 | 현재기/최대기 × 5.0 | 전량 |

### 원소 상성표

| 공격↓\방어→ | 목 | 화 | 토 | 금 | 수 | 무 |
|-------------|---|---|---|---|---|---|

| 화 | 1.0 | 1.0 | 0.7 | 1.5 | 0.7 | 1.0 |
| 토 | 0.7 | 1.0 | 1.0 | 0.7 | 1.5 | 1.0 |
| 금 | 1.5 | 0.7 | 1.0 | 1.0 | 0.7 | 1.0 |
| 수 | 0.7 | 1.5 | 0.7 | 1.0 | 1.0 | 1.0 |

### 유대 연계 배율

| 유대 단계 | 발동률 | 합산 배율 |

| 2(전우) | 5% | ×1.2 |

### 합체기 (유대 4 한정)

- 발동 조건: 양쪽 기 50%+
- 발동률: 20% / 라운드
- 기 소비: 양쪽 50%
- 위력: 극의 × 1.5

## 8. 환생 시스템

### 곡옥 획득

```
곡옥 = (클리어 지역 수 × 10)
     + (최고 Lv 모험가 ÷ 10)
     + (처치 보스 수 × 5)
     + (전설 아이템 수 × 3)
     + (도감 완성률 × 50)
```

### 환생 영구 보너스

```
스탯 보너스 = +5% × 환생 횟수 (누적, 상한 10회 = +50%)
경험치 보너스 = +15% × 환생 횟수 (누적, 상한 10회 = +150%)
※ 11회 이후 환생은 곡옥만 획득, 스탯/XP 보너스 추가 없음
```

### 환생자 특권

- 장비 착용 레벨 제한 무시
- 이전 클래스 도감 기록 → 전직 시 스탯/아이템 조건 면제 (레벨만 필요)

## 9. 요기 침식

```
침식 게이지: 0~100
축적 = 요기농도 × 0.01 / 틱 (원정 중)
감소 = 0.5 / 틱 (길드 대기)
저항 = SPI × 0.3% 만큼 축적 감소
깊이 가중 = 깊이 × 1.2 배율
```

### 침식 단계별 효과

| 단계 | 게이지 범위 | 상태명 | 효과 |
|------|------------|--------|------|
| 0 | 0~24 | 정상(正常) | 효과 없음 |
| 1 | 25~49 | 경미(軽微) | 물리/술법 방어 -5%, SPI -10% |
| 2 | 50~74 | 진행(進行) | 물리/술법 방어 -15%, SPI -25%, 이벤트 "요괴화" 플래그 |
| 3 | 75~89 | 심각(深刻) | 전 스탯 -20%, HP -10%, 원정 중 자해 행동 5%/턴, 케모노 계통은 STR/SPD +15% |
| 4 | 90~100 | 폭주(暴走) | 원정 불가, 정화약 필수, 3일 정화 필요. 케모노 T4+ "야차/나찰" 전직 조건 |

> 게이지 100 도달 시 자동 귀환. 영구 상실 없음 — 반드시 정화로 복귀 가능.
> 케모노 계통만 침식이 일부 유리하게 작용 (단계 3: STR/SPD 보너스, 단계 4: 전직 조건)

## 10. 펫 시스템

### 경험치

```
펫 XP = 파티 XP × 0.3
최대 레벨: 50
필요 XP = floor(10 × (Lv ^ 1.4))
```

### 패시브 스케일링

```
패시브 효과 = 기본값 × (1 + (펫Lv - 1) × 0.04)
```

### 보조 행동 발동률

```
발동률 = (펫Lv × 2)% (상한 100%)
위력 = 파티 평균 스탯 × 0.5
회복 = 파티 평균 SPI × 0.3
```

### 펫 유대 축적

```
유대 포인트 = 원정 1회당 +10 (같은 모험가와 동행 시)
단계: 0(낯섦)=0, 1(친숙)=50, 2(파트너)=150, 3(영혼의 벗)=300

## 17. 조우 시퀀스 생성 알고리즘

```typescript
function generateEncounterSequence(
  seed: number,
  region: RegionId,
  depth: 1 | 2 | 3 | 4 | 5,
  expeditionCount: number
): EncounterData[] {
  // 보스전은 고정
  if (depth === 5) {
    return [{ type: 'combat', seed: seed, resolved: false }]; // 보스 1체
  }

  const rng = seedRandom(seed ^ hashRegion(region) ^ depth ^ expeditionCount);
  const encounterCount = ENCOUNTER_COUNTS[depth]; // {1:4, 2:8, 3:12, 4:18}
  const weights = ENCOUNTER_WEIGHTS[depth];        // 조우 유형 가중치표

  const sequence: EncounterData[] = [];
  let consecutiveCombat = 0;

  for (let i = 0; i < encounterCount; i++) {
    const encounterSeed = seed ^ (i * 31) ^ depth;

    // Step 1: 첫 조우는 항상 전투
    if (i === 0) {
      sequence.push({ type: 'combat', seed: encounterSeed, resolved: false });
      consecutiveCombat = 1;
      continue;
    }

    // Step 2: 마지막 조우는 항상 전투
    if (i === encounterCount - 1) {
      sequence.push({ type: 'combat', seed: encounterSeed, resolved: false });
      break;
    }

    // Step 3: 연속 전투 3회 → 비전투 강제
    if (consecutiveCombat >= 3) {
      const nonCombatType = rng() < 0.5 ? 'camp' : 'discovery';
      sequence.push({ type: nonCombatType, seed: encounterSeed, resolved: false });
      consecutiveCombat = 0;
      continue;
    }

    // Step 4: 가중치 기반 선택
    const roll = rng();
    let cumulative = 0;
    let selectedType: EncounterData['type'] = 'combat';

    for (const [type, weight] of Object.entries(weights)) {
      cumulative += weight;
      if (roll < cumulative) {
        selectedType = type as EncounterData['type'];
        break;
      }
    }

    sequence.push({ type: selectedType, seed: encounterSeed, resolved: false });
    consecutiveCombat = selectedType === 'combat' ? consecutiveCombat + 1 : 0;
  }

  return sequence;
}

// 방치 시: 안전 루트 적용
function applyIdleRoute(sequence: EncounterData[], rng: () => number): EncounterData[] {
  const keepRatio = 0.6 + rng() * 0.1; // 60~70%
  const keepCount = Math.max(2, Math.floor(sequence.length * keepRatio));
  // 전투 조우를 우선 제거 (발견/야영은 유지)
  const combatIndices = sequence
    .map((e, i) => e.type === 'combat' ? i : -1)
    .filter(i => i > 0 && i < sequence.length - 1); // 첫/마지막 제외

  const toRemove = sequence.length - keepCount;
  const removeIndices = new Set(
    shuffleArray(combatIndices, rng).slice(0, toRemove)
  );

  return sequence.filter((_, i) => !removeIndices.has(i));
}
```
