## 화면 전환 다이어그램

```
[타이틀]
  ├─ 새 게임 → [길드 홈] (+ TUT-001 이벤트 모달)
  └─ 불러오기 → [길드 홈] (+ 부재 중 보고서 모달, 복귀 시)

[길드 홈] ← 메인 허브, 항상 돌아올 수 있음
  ├─ 사이드바 "원정" → [원정]
  ├─ 사이드바 "모험가" → [모험가 목록]
  ├─ 사이드바 "시설" → [시설 목록]
  ├─ 사이드바 "제작" → [제작]
  ├─ 사이드바 "도감" → [도감]
  ├─ 사이드바 "설정" → [설정]
  ├─ 이벤트 알림 클릭 → [이벤트 모달]
  └─ 퀘스트 알림 클릭 → [퀘스트 모달]

[원정]
  ├─ 슬롯 클릭 (빈 슬롯) → 편성 모드
  │   ├─ 파티 선택 → 모험가 선택 UI
  │   ├─ 목적지/깊이 선택 → 드롭다운
  │   ├─ 소모품 장착 → 인벤토리 선택
  │   ├─ 자동 반복 토글
  │   └─ [파견] → 원정 시작, [원정] 화면으로 복귀
  ├─ 슬롯 클릭 (진행 중) → [전투 로그] (능동 관찰)
  └─ 슬롯 클릭 (완료) → [원정 결과]

[전투 로그]
  ├─ 실시간 텍스트 스크롤
  ├─ [다음 조우] → 다음 조우 진행
  ├─ [원정 요약] → [원정 결과]
  └─ 이벤트 조우 발생 → [이벤트 모달]

[원정 결과]
  ├─ 전리품 확인
  ├─ [확인] → [원정] (자동 반복 시 자동 재파견)
  └─ 레벨업 발생 → [레벨업 모달]

[모험가 목록]
  └─ 모험가 클릭 → [모험가 상세]

[모험가 상세]
  ├─ [전직] → [전직 모달] (조건 충족 시만 활성)
  ├─ [장비 변경] → 장비 선택 UI (인벤토리에서)
  ├─ [훈련 배치] → 도장에 배치 (도장 해금 시)
  └─ [은퇴] → [확인 모달] → 은퇴 처리

[시설 목록]
  └─ 시설 클릭 → [시설 상세]

[시설 상세]
  ├─ [업그레이드] → [확인 모달] (비용 표시)
  ├─ [제작] → [제작] (해당 시설 필터)
  └─ [배치/해제] → 모험가 선택 (도장/다실)

[제작]
  ├─ 시설 탭 선택 (대장간/약제실/주방/부적방)
  ├─ 레시피 선택 → 소재 확인
  └─ [제작 시작] → 대기열에 추가

[도감]
  ├─ 탭: 요괴/아이템/클래스/이벤트
  └─ 항목 클릭 → 상세 정보 표시

[설정]
  ├─ 게임 설정 (텍스트 속도, 사운드 등)
  ├─ [백업 내보내기] → JSON 다운로드
  ├─ [백업 가져오기] → 파일 업로드 → [확인 모달]
  └─ 게임 정보/크레딧
```

## 모달 우선순위 (동시 발생 시)

```
1. 부재 중 보고서 (최우선, 복귀 시 무조건 표시)
2. 이벤트 모달 (이벤트 선택은 즉시 처리)
3. 레벨업/전직 모달
4. 아이템 획득 알림
5. 퀘스트 완료 알림
```

- 모달은 **스택**: 여러 모달이 발생하면 순서대로 표시
- 부재 중 보고서 내에서 이벤트 선택 → 보고서 내 인라인 처리

## 키보드 네비게이션

| 키 | 동작 |
|----|------|
| Tab | 인터랙티브 요소 순회 |
| Enter/Space | 선택/확인 |
| Escape | 모달 닫기 / 이전 화면 |
| 1~7 | 사이드바 탭 단축키 (길드/원정/시설/모험가/제작/도감/설정) |
| ←→ | 탭 내 서브탭 전환 |
| ↑↓ | 리스트 항목 순회 |

## 반응형 분기점

| 너비 | 레이아웃 | 사이드바 |
|------|---------|---------|
| ≥ 1024px | 사이드바 + 메인 | 항상 표시 |
| 768~1023px | 메인만 | 하단 탭 바 |
| < 768px | 메인만 (폰트 축소) | 하단 탭 바 (아이콘) |

## 상태 전환 제약

| 현재 화면 | 차단 조건 | 이유 |
|-----------|----------|------|
| 원정 편성 | 모험가 < 1명 idle | "파견할 모험가가 없습니다" |
| 전직 모달 | 조건 미충족 | 버튼 비활성 + 부족 조건 표시 |
| 보스 원정 | 깊이4 클리어 < 3회 or Lv 미달 | "조건을 충족하지 못했습니다" |
| 시설 업그레이드 | 금화/소재 부족 | 비용 빨간색 표시 |
| 환생 | 조건 미충족 | 버튼 숨김 (조건 충족 시 출현) |

## 알림 시스템

| 알림 유형 | 표시 위치 | 지속 |
|-----------|----------|------|
| 원정 완료 | 하단 알림 바 + 원정 탭 뱃지 | 확인할 때까지 |
| 이벤트 발생 | 하단 알림 바 (강조) | 선택할 때까지 |
| 제작 완료 | 하단 알림 바 + 시설 탭 뱃지 | 5초 후 사라짐 |
| 레벨업 | 모달 자동 표시 | 확인 클릭까지 |
| 퀘스트 완료 | 하단 알림 바 | 5초 후 사라짐 |
| 모집소 갱신 | 모험가 탭 뱃지 | 확인할 때까지 |
